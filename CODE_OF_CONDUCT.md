# Code of Conduct

## Our Pledge
We pledge to make participation in our project a harassment-free experience for everyone.

## Our Standards
Examples of behavior that contributes to a positive environment include:
- Using welcoming and inclusive language
- Being respectful of differing viewpoints
- Gracefully accepting constructive criticism

## Enforcement Responsibilities
Project maintainers are responsible for clarifying standards and taking appropriate corrective action.

## Scope
This Code of Conduct applies within all project spaces and in public spaces when representing the project.

## Enforcement
Instances of abusive or unacceptable behavior may be reported to the project maintainers.

## Enforcement Guidelines
Project maintainers will follow these guidelines in determining consequences for any action they deem in violation.

## Attribution
This Code of Conduct is adapted from the Contributor Covenant.
